# FedASAP - Activation-Statistics Driven Structured Adaptive Pruning for Efficient Personalized Federated Learning for Lesion Segmentation on brain MRI

FedASAP is a federated learning framework for medical image segmentation with adaptive structured pruning capabilities. This repository implements various federated learning methods with model compression techniques for efficient distributed training.
